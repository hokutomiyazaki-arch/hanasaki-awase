# 鼻先あわせ（FNT）

目を閉じたまま、鼻先を狙った所へ向けられるかをスマホのカメラで測る単体のアプリ（PWA）。FNTアドバンス講習の受講者（トレーナー）に配る。

- 公開URL：https://hokutomiyazaki-arch.github.io/hanasaki-awase/ （カメラは https が要るので GitHub Pages）
- 元：`~/FNT-Apps/fnt-camera-check/index.html` の「14・15. 鼻先を合わせる①②」（2026-10-18 時点の公開版）
- 🔴 **元の fnt-camera-check の鼻先の検査を直したら、こちらにも同じ直しを移すこと。** 鼻先の検査（`NOSE_SQ`〜`runNoseB`・`demoNose`）と、カメラ・音声・安定化の部品は元のコードをそのまま写してある。違うのは次だけ
  - 題名：「14. 鼻先を合わせる①（…）」→「① 目を閉じて真ん中へ」「② 目を閉じて8つの点へ」
  - テストの終わり：元の `recorded()` の代わりに `done()`（続きがあればその場に結果と「次へ」、最後なら結果の画面へ）
  - `demoNose(kind, c)`：描くキャンバスを渡せるようにした（トップの見本）。`noseAB` は①を2回→②を2回
  - お客さん用の仕組み（`BACK`・ファネル）とほかの検査は持ち込んでいない
- 映像は端末の外へ送らない（MediaPipe FaceLandmarker・tasks-vision 1.1.0 を CDN から読む）

## 中身
- スプラッシュ「タップで開始」→ トップ：「①目を閉じて真ん中へ」「②目を閉じて8つの点へ」「①→②を続けて」（それぞれ説明ひとことと線画の見本）
- 始めると、カメラの許可 → 元の位置合わせ（距離・向き・明るさ。顔が無いときの扱いも元のまま）→ テスト
- テストの動き（元と同じ）：真ん中の点は鼻先が重なるまで待つ・重なると緑・「スマホを動かして、鼻先を真ん中の点に」・真ん中の点は映像の上から58%・点までの距離 0.165・確定位置の赤い点は小さく黄色は輪・②は1か所ずつ・練習2か所（記録しない）・結果は8か所が終わってから
- 結果：元の `noseHTML`（ズレの平均・いちばん大きい向き・ズレの図・8方向の一覧）をそのまま出す
- 記録：この端末の localStorage `hanasaki_runs`（最新30件）。☰メニュー「これまでの記録」で日時ごとに開ける。結果の画面で「記録をテキストでコピー」
- ☰メニュー：使い方／これまでの記録／音声オン・オフ（`hanasakiVoice`）／ホーム画面への追加（iPhone・Android）／著作権
- テスト中：左上「↺ 最初からやり直し」・右上「✕ やめる」（このアプリで足した）・「🔊 音声オン」
- 安定化（元のまま）：カメラが止まったら自動で開き直す・Wake Lock・GPU で顔が取れなければ CPU へ・公開中の版が新しくなっていたら読み込み直す。トップに戻るとカメラを手放す

## 音声
- `voice/*.mp3` は元の fnt-camera-check の voice から、このアプリで読む文（39文）だけをコピーしたもの。対応表は `voice/index.json`
- 文を変えたら `python3 tools/voice_build.py`（`--dry` で一覧と字数）。元にある文はコピー、無い文だけ ElevenLabs（eleven_v3・リョウ）で作る
- コンソールに「[voice] 音声ファイルなし」が出たら、その文を `tools/voice_build.py` の EXTRA に足して走らせ直す

## 更新のしかた
- `index.html` や `voice/` を変えたら `sw.js` の `CACHE_NAME` の版を上げる（Network First なので上げ忘れても新しい版は届くが、古いキャッシュが残る）

## 試し方（作り物のカメラ）
- `python3 -m http.server` で開き、Chrome を `--use-fake-device-for-media-stream --use-file-for-fake-video-capture=<顔の映像.y4m>` で起動
- `?test=1` を付けたときだけ `window.__noseAt`（鼻先の位置を差し替える関数）と `window.__hanasaki` が効く。ふだんは何もしない。Service Worker も登録しない
